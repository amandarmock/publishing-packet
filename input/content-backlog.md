# Content Backlog

Working titles and one-line concepts for content already planned or published. The idea
generator reads this so it doesn't pitch what's already on the list, and so new ideas can
hang off existing ones.

## Planned
- **Agent Harnesses Explained in X Minutes** (Validating): A tight explainer on the scaffolding
  around a model that turns it into an agent (tool access, permissions, context management, the
  run loop) and why the harness matters as much as the model, using Claude Code as the worked
  example.
- **Agentic Workflows: What You Should Know** (Validating): A primer on what agentic workflows
  are, how they differ from simple automation and single-agent chat, and where they shine and
  fail, giving the audience the mental model before the hands-on builds.
- **Build an Automated Workflow With Me (Full Tutorial)** (Validating): A full tutorial where the
  audience picks a real repetitive task, designs the process, and automates it step by step
  alongside me, ending with a working automation they built themselves.
- **Claude Code Agent Teams (Foundational)** (Validating): A practical walkthrough of spawning
  subagents in Claude Code, giving them roles, and coordinating them on real work so one person
  can run what looks like a whole team.
- **Claude Code Full Master Class for beginners** (Validating): A complete zero-to-proficient
  Claude Code course covering install and setup, core workflows, skills, subagents, automation,
  and real projects, serving as the flagship long-form piece the rest of the series hangs off.
- **Context Master Class** (Idea): A master class on what actually gets loaded into a model's
  context window and when, what memory is and isn't, and how token usage accumulates over a
  session, so you can design a setup that stays sharp instead of quietly drowning itself.
- **Every AI Model Explained** (Validating): A guided tour of the major AI model families (Claude,
  GPT, Gemini, Llama, and the rest), what each tier is for, and how to match a model to a job
  without drowning in benchmarks.
- **Loops and Graphs Explained** (Validating): A plain explanation of the two core shapes of
  agentic systems, the agent loop and graph-based orchestration, when each fits, and how real
  products combine them.
- **My Framework for Deciding Which Agent and Model Does What** (Validating): A decision
  framework for which tasks get a subagent versus the main loop and which model tier each job
  deserves, weighing capability, cost, speed, and risk as a repeatable rubric.
- **X Things You Need to Know Before Building Agent Teams** (Validating): A listicle of the
  pitfalls, prerequisites, and mindset shifts nobody tells you about before you build your first
  team of AI agents.
